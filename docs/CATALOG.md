# 公共资料目录、发行版本与导入

公共目录用于检索 Web 已收录资料，与个人书架分开。资料来源和观测时间会显示在页面中；官方快照只包含选定公共表，不等于整个网站、全部图片或实时镜像。

## 浏览与查询

Web 默认进入“我的书架”，`/?view=local` 为公共资料目录，`/?view=remote` 为查询与收录。桌面也有独立公共目录入口，先填写条件，再点击“应用筛选并浏览”或按 Ctrl+Enter；翻页沿用已应用条件，读取失败保留原页。

支持标题、会社、发行语言、发行类型、平台和排序。所有筛选及排序先在全库执行，再分页；默认按“曾玩过 → 本地已有 → 其余资料”优先显示，不隐藏其余命中。也可选择标题、更新时间或发售日期排序。

多个发行条件须命中同一发行版；合集中的发行类型须匹配当前作品。语言默认排除机翻，可主动包含。筛选可能命中未来日期、试玩、补丁或部分翻译，不能据此认定本机版本已支持该语言。完整版本详情另列日期、官方／非官方、机翻和完整度。

公共卡片是摘要，不能作为完整 metadata 导出。明确打开完整资料或查询发行版本后再导出。没有个人经历显示“未记录”，明确待开始才算“未游玩”；公共汇总不把一个条目的经历或安装借给另一个条目。

目录零命中不会自动请求 VNDB；需要补全时使用明确查询／刷新入口。桌面可在 Web 不可达时显示完全相同筛选与页码的历史 JSON，显示原观测时间；无历史页会提示缺失，不承诺客户端全库离线检索。

## 官方资料导入

作品详情按公共资料、来源与公共评分、个人经历分别显示。页面的「显示标题偏好」可选日文、原始语言或罗马字，并附加日文副标题，保存在当前浏览器；不会改写作品或个人标题覆盖。

已收录发行目录支持本地筛选与每次20项展开，类型按当前作品与准确发行ID展示，不能据此认定本机安装了某语言版。直接关联只读取本库，不递归抓取整个关系网；缺失资料时回填ID并等待明确查询。个人管理页的关联在新页面打开，保留当前编辑草稿。

在 Web `/manage.html?tab=imports` 的“官方公共资料目录 → 资料更新”查看本库完整导入快照、最近发现的官方日期、检查结果及活动任务。页面读取和刷新状态不访问外网；“官方最新”表示上次成功检查的结果，不代表实时镜像。

“检查最新版”仅对官方 `vndb-db-latest.tar.zst` 发出 HEAD，读取日期化重定向，不下载全包。“检查并更新”先检查，再将较新的准确日期提交到原有导入队列；已有相同任务时复用，有其他进行中、暂停或失败任务时先处理原任务。仅完整导入成功后才更新本库快照日期，排队不表示已经更新。检查至少间隔15分钟，官方限流／维护时遵守等待时间；旧检查信息保留，失败或中断的检查不能据旧信息排入新更新。

展开“可选定时同步”可启用每1–30天检查并更新，默认关闭、间隔7天。首次启用在后台执行下一次检查；已接收的导入不因关闭定时开关而取消，仍可在任务上暂停。设置与检查摘要存在Web数据库，重启后继续遵守周期与等待时间；后台执行需启用`CatalogJobs:Enabled`（默认启用）。运行中改动定时设置，会使尚未排队的旧调度停止提交。网络故障按小时量级再检查，不创建额外服务。原包与暂存沿用现有保留规则，需持续关注数据卷空间；空间不足时任务保留并等待处理。

需要历史日期时，展开“手动指定官方导出日期”，或通过 API 上传预先下载的官方 `.tar.zst`。现存文件和许可见 [VNDB 官方下载目录](https://dl.vndb.org/dump/)。接口及格式见 [Web API](WEB-API.md#官方导出任务)。

- 日期任务只使用固定官方 HTTPS 地址，不接受任意下载 URL。
- 上传使用 `application/octet-stream`，最多 512 MiB，需要应用管理密钥及幂等键；压缩包不是 JSON，也不能直接作为 SQLite 文件使用。
- 只导入公共表白名单，不执行包内 SQL，不导入其他用户列表，不自动创建个人条目或游玩记录。
- 不批量下载全站图片；未缓存封面显示占位，可按需要明确补全。

导入前至少准备 4 GiB 额外空间；现有数据库、封面、索引、旧输入和备份另计。输入放在数据卷，不放容器的小容量 `/tmp`。

## 任务管理

页面可手动刷新、暂停、继续或取消；关闭页面不停止任务。`queued` 只表示接收，只有 `completed` 且覆盖计数通过校验才表示完成。暂停、失败和进行中任务不会冒充完整快照。

同一时间只允许一个活动任务，包含暂停或失败任务；完成或取消后再建立其他任务。同包或同日期重复提交会返回已有任务。409 时先刷新任务修订，结果不明时保留原请求与幂等键。遇上游限流遵循等待时间，不增加并发抓取。

JSON 导入批次和联网补全任务的自动刷新保留展开的逐项结果、键盘焦点及待确认原操作；读取失败保留最近成功显示，隐藏页面不轮询，慢请求不重叠。响应丢失时使用卡片中的「按原操作重试」；冲突或明确拒绝后，手动重新读取会保留原操作供核对。

合并进度可在重启后恢复；下载中断会重新下载，预检未完成会重新预检，不承诺 HTTP 字节续传。正常异常／取消只清理本次尚未被任务接收的临时文件，已接收输入及合并暂存保留。进程中断可能留下无引用临时文件，可使用下述预览核对。失败需检查后显式恢复。取消任务保留已提交公共资料和已接收原输入，不回滚正确资料。

“容量与暂存”显示数据卷可用空间、原包／输入与暂存占用、最近完整快照和等待原因。展开“手动清理可释放的暂存”，先生成预览，再明确确认。默认只列无引用临时输入、可识别的无引用预检暂存，以及散列核验通过的已完成暂存；保留原官方包、活动／暂停／失败任务输入、数据库、封面和完整备份。存在未完成任务时须先处理或取消，再执行清理。

预览校验文件可能耗时。执行前重新核对文件内容、时间信息、范围和任务引用；任何变化均停止。回复丢失时按原操作重试，清理中断后可用原预览和证明恢复；不要通过手工删除数据卷目录处理失败任务。清理回执保存在 Web 数据库，预览及恢复意图在数据卷 `dataset-cleanups`，无需额外容器或定时任务。

较新的已有资料、个人评价、时间及存在标记受到保护；快照缺席不删除旧作品。导出未提供的封面和公共评分继续保留原缓存，不把它们标成新下载。历史快照日期不能保证网站后续新增或修订已经收录；同步范围仍为当前选定公共表，其他网站内容与图片不自动全量获取。

## 备份与迁移

完成的公共资料在 `data/library.db` 内，可随完整快照恢复后离线查询。未完成任务要离线续跑，快照需显式包含已验证且由任务引用的原包／暂存输入；半包和未完成预检不能冒充完整恢复输入。

完整备份、原密钥与镜像的保管及恢复见 [Docker 手册](DOCKER.md#6-手动完整备份与隔离恢复)。建立另一台机器的独立库时使用[公共分发包](OFFLINE-DISTRIBUTION.md)，不要复制个人快照、原身份或原密钥。
