# 桌面端使用说明

适用版本：0.7.0。Windows x64 发布包自带运行时，保留完整目录后运行 `Vndb.Desktop.exe`。桌面提供书架、启动、本机管理和个人资料同步，完整数据库由 Web 维护。

## 1. 安装与首次连接

更新时退出旧客户端，将新包解压到独立目录后切换入口。程序位置与数据位置分离，不覆盖用户文档数据目录。

在“设置”填写 Web 根地址，例如 `http://nas.local:5187/`，输入应用管理密钥，点击“保存并应用”，再按 F5 刷新。地址仅支持 HTTP(S) 根地址，不带子路径或凭据。只读浏览可以不填密钥，联网收录和同步需要密钥。Windows 可按当前用户 DPAPI 加密记住应用密钥，不与其他用户或服务共用这份密文。

配置或书架读取失败时保留原件，并显示失败阶段。“设置 → 最近启动检查”可查看阶段、耗时、错误类别及固定建议，修正后重新尝试；不要通过清空 JSON 绕过错误。“导出脱敏启动报告”仅含允许字段，不含异常原文、地址、路径或个人内容，也不替代数据备份。

## 2. 本机数据和备份

默认根为系统“文档”下的 `VndbLocal`，实际位置在设置中显示；不按用户名拼接路径，也不使用 NAS 共享目录作为客户端数据根。`VN_DESKTOP_HOME` 可覆盖整个数据根，查询缓存根仅改变查询 JSON 的位置。

安装、组件、EXE、参数、工作目录、全局 Locale Emulator、整理回执和修复备份均只在本机。查询缓存、离线个人编辑与回执按 Web 服务作用域隔离。备份前退出客户端，保存整个数据根并独立保管应用密钥；只备份程序目录无法恢复启动配置。具体文件见[数据与隐私](DATA-AND-PRIVACY.md)。

大量旧登记可使用 [CLI 索引迁移](CLI.md#本机登记的轻量索引迁移)将重资料拆分为本机 JSON，先退出客户端并备份，不混用旧程序写入新索引。

## 3. 书架、查询与个人分类

“我的书架”“游玩记录”“查询作品”分别保留浏览状态。支持卡片／封面列表、会社、游玩状态、本机资源筛选及添加时间、发售时间、会社、上次打开等排序；收藏、虚拟集合与标签可以组合筛选。快捷视图包括本机已安装、仅有安装包、缺失／待核对、已有且未玩等。

单击选择，Enter／双击打开详情，窄窗 Esc 关闭详情，F5 刷新。右键菜单提供直接启动、LE 默认启动、打开目录、配置、登记和快速游玩编辑，不可用项显示原因。右上角按钮切换明暗主题，外观设置支持标题偏好与减少动画。标题偏好只改变显示，不重命名文件。

个人书架先读取轻量摘要，完整简介、备注、发行目录及游玩明细在打开详情时读取。读取失败保留原页；离线仅能显示已缓存详情，未加载不等于未玩。没有经历为“未记录”，明确待开始且没有玩过历史才是“未游玩”；重玩和资源消失不抹去以往经历。

查询默认先访问 Web 本库，缺失由 Web 联网收录；Web 不可达时使用本机快照或 Core 直连 VNDB，生成可导入 JSON。鉴权、冲突、协议错误或限流不静默绕过 Web。公共目录按全库条件筛选后分页，离线仅回显相同条件与页码的历史 JSON，见[公共资料目录](CATALOG.md)。

作品详情区分公共资料、个人资料和本机资源。发行版的语言、机翻、完整度、平台及日期不证明本机安装了对应版本；可在查询页按作品 ID 显式读取／刷新发行目录。关联详情只读已有直接关联，缺资料时先回填 ID，再明确查询。

封面优先通过 Web 缓存读取；未补齐可在 Web 排入补全，完成后刷新。未关联或确认无图保留占位，不凭标题猜图。

详情中可编辑收藏、创建／改名／移除虚拟集合与标签，支持预览后将当前页归类。分类是扁平关系，不创建磁盘目录；移除分类不删除作品或文件。同一作品的不同个人版本分别管理。分类离线稿按当前服务保存，冲突时保留原稿再重读；“同步离线修改”提交原操作。

最近搜索只记录显式提交的关键词，可删除或清空；选择历史只是回填，仍需确认查询。它是本机／浏览器偏好，不同步 Web。

## 4. 本机安装、安装包与资源档案

从详情的“登记／重新核对本机安装”进入：

1. 选择完整游戏或合集目录，核对作品和会社。
2. 单作选择准确个人条目；合集／特典分别登记组件及相对位置，保留完整物理容器。
3. 预览并确认登记；此步骤不移动文件或启动程序。
4. 使用“同步资料与存在标记”，先取得准确条目映射，再提交存在布尔值。

安装包从目录整理页扫描文件名，或从卡片菜单“登记安装包”选择准确条目。支持常见压缩包／镜像，不解压、挂载或执行；分卷首卷不证明整套完整。根不可读、文件变更等保持未知，不能直接视为卸载。“Web 上报已有”也不证明当前电脑有可启动安装。

详情的“本机资源档案”可登记安装包、补丁、存档、特典和说明，填写检索根、根内相对位置及可选语言、版本、适用发行和人工核对结果。文件存在、适用判断、已手工应用和文件摘要分别记录，不自动应用补丁或创建启动入口。检查只读元数据，SHA256 仅在明确选择文件后按需计算，可取消；资源档案不上传 Web。

可选“本机变化观测”在设置中保存明确的游戏／包根及深度，默认关闭。“会社／游戏”布局通常为 2 层。自动观测仅在桌面运行时对本机 NTFS 范围工作，不安装系统服务；可手动“立即检查本机变化”。浅层监听配合周期复核，不递归监听全部游戏内容。

新目录／包先成为待匹配候选，稳定后仍需选择准确作品并确认登记，不自动查询或信任新 EXE。缺失需再次确认，根断开、身份变化或证据不足保持未知。发现相同物理身份的新位置只提供映射线索，不自动改写路径。观测结果沿用原同步周期提交布尔值，整理／复原未完成时暂停解释相关缺失。

## 5. 启动配置与 Locale Emulator

“本机启动”选择现有配置或新增独立配置，填写启动程序、参数、工作目录及可选安装／组件关联，再保存。预览和启动均使用**已保存配置**，右侧草稿需先保存。自动发现的候选仍需核对，应排除配置工具、卸载器和补丁程序。

包装器示例，以下均为示例路径：

| 字段 | 值 |
| --- | --- |
| 启动程序 | `F:\VN\Example Studio\Example Game\AlphaROMdiE.exe` |
| 参数 | `SiglusEngine.exe` |
| 工作目录 | `F:\VN\Example Studio\Example Game` |

程序栏只填可执行文件；含空格的单个参数加引号，复杂参数可使用高级 JSON 数组。不要将整条命令放入程序栏，不自动执行导入 JSON 中的命令或不明快捷方式。

在设置中指定全局 LE 工具，读取并选择默认语言配置，保存后可在卡片或启动页选择“直接”或“LE 默认配置”。配置只存本机，不改系统区域；转区不改变游戏自身的语言版本。独立入口可不关联 Web，基本启动不依赖联网或计时。

## 6. 启动诊断与修复

书架右键“启动诊断与修复”，选择准确安装／组件，点击“检查引擎与路径”。诊断显示程序版本证据、包装器、实际程序和工作目录；有核验通过的移动回执时可带出旧位置，否则手工填写。先看结论和建议，再展开路径／注册表高级项。

| 范围 | 行为 |
| --- | --- |
| 已保存启动配置 | 核对程序摘要后，预览修正程序、工作目录、跟踪程序及可确认的独立绝对路径参数；复杂参数保留手工配置 |
| AdvGame Module | 预览修正 `install.inf` 的 `[PATH] Current`，仅在原同目录时同步 `CDDrive`；保留 CP932 编码和本机备份，二进制 `env.ini` 不改写 |
| AdvHD | 提供路径编码／长度诊断；可明确选择短 ASCII 别名，进入完整目录整理预览 |
| 厂商注册表路径 | 按旧路径查找 HKCU／HKLM Software 字符串，区分 32／64 位视图；选择具体值、预览、确认退游后备份并写后核对 |

切换安装／组件、修改启动草稿或旧位置使原批准失效。权限不足、外部修改或身份不符时停止；部分注册表写入失败可从逐项记录核对。修复结果只确认路径与配置，实际运行仍需验证。

修复备份按安装、组件和目录身份定位；经过已核验整理移动后，可在当前位置预览恢复。移动链缺失、组件不符或配置已改动时拒绝恢复。原路径记录与文件字节保持不变，连续回迁须按当前修订重新预览。

## 7. 游玩、评价与同步

右键“快速更新游玩”或进入准确经历编辑，填写状态、日期、历史分钟、评分、感想和两栏备注。重玩有独立经历 ID，不按标题或 VNDB ID 覆盖。未知时间／评分留空，手工基数、自动会话和调整分开保存。

“本机已保存”“Web 已接收”“等待补全”“冲突待核对”是不同结果。断线或结果不明保留原稿、操作 ID 和内容，重连重试原操作；409 后明确重读并比较。“字段对照”展示原值、Web 当前值和本机稿，GET 内容相同不等于写入已确认。

metadata JSON 在 Web 导入页预览／提交；活动、评价与会话使用 `/sessions.html`。完整客户端根、扫描报告、注册表备份或移动回执不能上传。

可选会话计时按明确经历开始、暂停、恢复和结束，按准确进程身份跟踪。包装器另起进程时需核对实际游戏进程，不仅凭包装器退出判断退游。系统睡眠／休眠后继续运行由用户处理，可预先暂停或结束；基本启动不依赖计时成功。

## 8. 目录整理与复原

选择明确源范围与同卷目标根，按 `目标根/会社/游戏日文兼容名` 生成计划，核对关联、路径、冲突及批准摘要后执行。重扫或条件变化使旧计划失效。

只移动完整容器，保留内部游戏／特典结构；不复制、删除游戏、创建链接或合并重名。已有会社布局优先保留，兼容别名规则见[目录命名](FILESYSTEM-NAMING.md)。碰撞、歧义或身份变化停止执行。

中断按原回执续跑。复原先预览当前完整目录，再按新摘要批准回迁，保留移动后新增存档。证据只在本机；首次建议从一个明确完整目录开始核对。

## 9. 常见问题

| 现象 | 检查 |
| --- | --- |
| 更新后找不到启动配置 | 实际数据根、当前系统用户及 `VN_DESKTOP_HOME`；先备份再核对 JSON |
| 浏览成功但补全／同步失败 | Web 地址、应用密钥及服务能力；401 不自动回退 |
| Web 显示已有但无法启动 | 本机登记、准确 EXE 及已保存配置；存在布尔值不含启动位置 |
| 特殊符号路径打不开 | 先诊断并预览兼容命名，不随意改内部资源或 EXE |
| JSON 损坏／并发冲突 | 保留原件，根据来源、修订和回执恢复，不重置为空书架 |

服务端安装与恢复见 [Docker／NAS](DOCKER.md)，数据边界和备份范围见[数据与隐私](DATA-AND-PRIVACY.md)。
