存在标记是客户端上报；Web不判断安装、包或启动就绪。
顺序：资料库默认 · 全库筛选后分页

官方公共资料目录

按日期下载官方导出并在后台验证、导入；不会加入个人书架。需预留至少4GiB额外空间，封面按需补全。

尚未读取；任务可在关闭页面后继续。

导入本机资料

支持 metadata v1 完整快照／清单，以及已知旧 CLI／Web 导出。完整快照可以离线入库；清单和封面在现有容器内慢速补全。不会打开 JSON 中的路径或执行命令。

导入记录与进度

读取进度后展示接收与处理状态。

联网补全任务

同一 Web 容器串行执行，任务间隔至少5秒，失败退避后最多三次；关闭页面后继续。

接收批次与资料处理分开；候选待核对及失败项请展开逐项结果。刷新失败保留最近成功显示。

需要你的确认

客户端快照不会因时间较新就覆盖现有资料。请比较候选；书架关联确认会保留条目 ID、游玩记录与来源。

已移除的书架条目／游玩记录

移除保留原行、来源及历史，可恢复。没有删除游戏或封面，也不会级联删除其他个人记录。

资料库管理密钥

使用现有 Web 管理密钥，不能使用 NAS SSH 密码。
